# menkyo-watcher

警視庁 仮免許 予約サイト（府中・鮫洲）で 11/6〜11/27 に空きが出たら、スマホに通知します。
GitHub Actions 上で1分ごとに確認するので、PCを起動しておく必要はありません。
（1回の実行が約5時間40分ループし、終わるとすぐ次の実行が始まります）

## セットアップ

1. **スマホに ntfy アプリを入れる**（iOS / Android、無料・登録不要）
   - アプリで「+」→ 他人に推測されにくいトピック名で購読（例: `menkyo-a8f3k2x9q`）
2. **GitHub にこのフォルダを push する**（public リポジトリ推奨。private だと無料枠を超えます）
3. リポジトリの **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `NTFY_TOPIC` / Value: 1で決めたトピック名
4. **Actions タブ → check-vacancy → Run workflow** で手動実行し、成功するか確認

## 動作

- 新しく空いた枠だけを通知します（同じ枠で何度も通知されません）
- 通知をタップすると予約サイトが開きます
- 監視範囲や試験場は `.github/workflows/check.yml` の `DATE_FROM` / `DATE_TO` / `PLACES`（270=府中, 280=鮫洲）で変更できます
- 確認間隔は同じファイルの `INTERVAL_SECONDS` で変更できます（相手サイトの負荷を考え60秒以上を推奨）

## 自動予約と乗り換え

`AUTO_BOOK=1` のとき、予約がなければ最も早い空き枠を自動で予約します。予約後も監視を続け、今の予約より早い「日」に空きが出たら、いまの予約を取り消して早い枠を取り直します（同じ日の午前・午後の違いでは乗り換えません）。
乗り換え先の予約に失敗したら元の枠を取り直し、それも失敗したら通知します。予約日が当日以前なら乗り換えません。

- 追加の Secret: `STATE_KEY`（任意の長いパスワード）。現在の予約（予約番号など）をこの鍵で暗号化して `reservation.enc` としてリポジトリに保存します。
- 自動予約・乗り換えの対象は、今日から7日以上先の枠だけです（`MIN_LEAD_DAYS`）。空き通知は全部の枠が対象です
- 満席などで予約できなかった枠は `switch_skip.json` に記録し、その枠の空きが一度消えるまで予約・乗り換えの対象にしません。乗り換えの途中で中断されると `switch_in_progress.json` が残り、自動予約を止めます（予約状況確認/キャンセルで確認し、`autobook_stopped.json` と一緒に消すと再開）
- `STATE_KEY` が未設定だと自動予約はしません
- 予約者情報は Secret の `BOOK_NAME` / `BOOK_BIRTHDAY` / `BOOK_PHONE`
- 想定外のエラーが出ると `autobook_stopped.json` ができて自動予約が止まります（空き通知は続きます）。原因を確認して、このファイルを消すと再開します
- 予約の送信結果は「成功」「満席・予約できない日と確定した失敗（B4001 / B4002 / B4004）」以外をすべて「結果不明」として扱い、元の枠の取り直しはせず自動予約を止めて通知します
- 状態ファイルは各回の実行の終わり（約340分ごと）にまとめてコミットされます。実行の途中でランナーが落ちると最新の状態が失われることがあり、その場合は次の乗り換えの事前確認で止まります
- `reservation.enc` を消すと「予約なし」扱いになります。`STATE_KEY` を変えると読めなくなり自動予約が止まるので、変えるときは `reservation.enc` も消してください

## 止まったときの戻し方

1. 予約サイトの「予約状況確認/キャンセル」で、いま予約が入っているか確認します
2. ツールが把握していない予約が入っていたら、サイトでキャンセルするか、自動予約を止めたままにします
3. 再開するには `autobook_stopped.json`（と、あれば `switch_in_progress.json`）を削除してコミットします
4. `reservation.enc` を削除すると、ツールは「予約なし」と判断します（実際に予約があるのに消さないでください）

## ローカルで試す

```
python check.py
```

## iPhone 自動入力スクリプト（karimen-autofill.user.js）

通知 → 利用規約に同意 のあと、「仮免許学科試験」選択・予約者情報入力・鮫洲の選択までを自動で進め、カレンダーを表示します。
日付・時間の選択と最終確定は手動です。個人情報はスマホ内のスクリプトにだけ保存し、このリポジトリには入れません。
